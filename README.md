# Lucky David: portfolio website

Plain HTML, CSS and a little JavaScript. No build step.

Files:
- index.html (portfolio home)
- school-socks.html, dear-diary.html, how-we-got-here.html, manifesto.html, writing-challenge.html, social-content.html (writing samples)
- images/ (the two sample images)

To update your details, open index.html and look for the block marked
"Fill these in" near the bottom. It holds your social links, CV link, skills,
education and certifications.
